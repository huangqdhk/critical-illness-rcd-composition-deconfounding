## 3. 排除与纳入规则（来源互斥原则）

1. **GSE310929 永不作为独立队列**进入任何 meta 或"独立复制"表述；其 3713 例按 `Dataset` 列拆回 28 个原始数据集，每样本只计一次。
2. GSE185263（392）与 GSE32707（144）作为 28 来源中的两个自然保留；不再与其母集合并。
3. 纵向重复采样（GSE212865 等）：主分析保留预注册基线时点，敏感性分析用患者随机截距；同一患者不得作为多个独立单位。
4. 单细胞：细胞不作独立单位；cell type × donor pseudobulk，供者数为有效 n（edgeR/DESeq2/limma-voom 任一，主分析用 DESeq2，其余作敏感性）。
5. 空间：patient–slide–FOV 三级映射；主分析=患者内汇总后的患者级检验或患者阻断置换；切片/FOV 不作独立生物重复。

## 4. 统计方法（冻结）

- 数据集级效应：每数据集独立估计 Hedges' g（或 log2FC+SE），不合并原始样本。
- meta：REML + Hartung-Knapp，报告预测区间；异质性报告 τ²、I²、Q。
- 稳定性：leave-one-source-out（28 次）。
- 多重检验：BH-FDR，家族按"终点×分析层"定义。
- 主对比族沿用现行预注册（SepsisCOVID_vs_Control、ARDSd0_vs_Control 及其余队列主对比），不新增事后对比。

## 5. 判定门槛（Go/No-Go，抄自方案 Phase 0/1/2，不修改）

**Phase 0（重算后）：**
- 上游塌陷与执行诱导在正确统计单位下**均不稳定** → 停止双臂机制叙事，改为描述性线粒体应激研究；
- **仅上游塌陷稳定** → 标题与摘要只写 mitochondrial infrastructure suppression，不写双臂；
- **完整双臂在 ≥2 个来源互斥队列稳定** → 进入 Phase 1，仍不称 Mitoxyperilysis。

**Gate 1（P1-2）：** 存在稳定 LPS×CS 交互签名（交互项 FDR<0.05，leave-one-replicate-out 方向稳定，与 GSH/氧化代谢方向一致）→ 冻结 IIAMD-up/down；否则不构建"Mitoxyperilysis 转录签名"。

**Gate 2（P2-2）：** 实验锚定签名在 ≥2 来源互斥真 ARDS 队列同向复制（供者级 FDR<0.05，髓系定位，组成调整后仍在）→ 强通过；仅脓毒症/单一队列 → "候选相关程序"；只反映泛危重症/细胞组成 → 撤回疾病映射。
